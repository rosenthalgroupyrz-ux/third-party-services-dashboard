# Third-Party Services Dashboard

A class project that connects Claude Code to third-party services (Gmail, GitHub, Notion, Linear and one extra service per group member) through each vendor's official MCP server, downloads test data into `dataExports/`, and searches it from a local dashboard website.

All accounts and data in this repository are fictional test data ("Project Atlas"). No real personal data or credentials are stored here.

This README is a placeholder and will be expanded with setup, usage and the group's contributions as the project is completed.
